# Distribution Billing & Product Management App

Local billing web application built with Streamlit, SQLite, and ReportLab.

## Features
- Dynamic cart with MRP vs Distributor Rate distinction
- Shop-specific price adjustments (Fixed Rupee)
- Product image upload and card background color support
- Historical price snapshot isolation
- In-place bill editing and PDF regeneration
- Timestamped database backups
